Así se ve Claude cuando trabaja en equipo

orquesta es un plugin gratis de Claude Code que muestra en vivo a cada subagente trabajando.

Ver en GitHub

Qué muestra

  • Agente principal (Opus) y cada subagente (Sonnet, Haiku)
  • Modelo, tarea, acción actual, temporizador y tokens de cada uno
  • Árbol cuando un subagente lanza otros
  • Tarjeta roja si algo falla
  • Sonidos al empezar y al terminar
  • Resumen final del trabajo
  • Verlo no gasta tokens: solo dibuja eventos que Claude ya produce

Funciona en la app de escritorio de Claude, pestaña Code (Claude Code).

Instálalo en 1 minuto

1) Terminal

claude plugin install orquesta --marketplace obedsamudio/orquesta --scope user

2) Chat de Claude Code

/plugin marketplace add obedsamudio/orquesta
/plugin install orquesta@orquesta
/reload-plugins

3) Pídeselo a Claude

Instala el plugin de https://github.com/obedsamudio/orquesta y ábrelo
