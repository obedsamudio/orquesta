# Seguridad

Este plugin no usa claves de API, servidores ni servicios de pago. Solo dibuja en Claude Code los eventos que Claude ya produce.

Si encuentras un problema de seguridad, no abras un issue público: usa **Security → Report a vulnerability** en este repositorio.

Instala el plugin solo desde este repositorio oficial. Si alguien te pasa una copia modificada, revisa el código antes de instalarla.
